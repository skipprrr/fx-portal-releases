# FX Portal — downloads

Search and apply any effect, preset, transition or file in Adobe Premiere Pro with one shortcut.

## Install
1. Download the newest zip from [`builds/`](builds/) (or from the link in `latest.json`).
2. Right-click → **Extract All**.
3. Close Premiere, double-click **Install FX Portal.cmd**.
4. Open Premiere, wait a few seconds, press **Ctrl+Space**.

Once installed, FX Portal updates itself (Settings ▸ Updates).

---
This repository only holds finished installers and the update feed (`latest.json`) that FX Portal reads.
